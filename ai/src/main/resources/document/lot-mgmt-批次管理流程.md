# 批次管理流程

## 入库流程
1. 供应商送货到达，仓管员核对送货单与采购单。
2. 录入批次信息：SKU、温区、生产日期、过期日期、数量、供应商。
3. 系统自动生成批次号（格式 LOT + 日期 + 流水号）。
4. 批次状态置为 IN_STOCK（在库）。
5. 同步写入库存记录，增加可用库存量。

---

## 出库流程（FEFO 策略）
1. 订单触发出库，指定 SKU、温区、数量。
2. 系统按 FEFO（先过期先出）策略匹配批次：优先选择过期日期最早的批次。
3. 逐批加锁，扣减批次剩余量，同步扣减库存可用量。
4. 批次剩余量为 0 时状态置为 FULLY_OUT（已出清）。
5. 写入流转记录（t_lot_transfer），记录出库时间、数量、去向。

---

## 转库流程
1. 源批次加锁，校验剩余量是否充足。
2. 扣减源批次剩余量，同步扣减源库位库存。
3. 创建或追加目标批次（同 SKU + 温区 + 生产日期可合并）。
4. 增加目标批次剩余量，同步增加目标库位库存。
5. 写入调拨流转记录，记录转库方向、数量。

---

## 批次状态机
- IN_STOCK（在库）：正常在库待出。
- PARTIAL_OUT（部分出库）：已出部分，仍有剩余。
- FULLY_OUT（已出清）：全部出库完成。
- EXPIRED（已过期）：超过过期日期，不可出库。
- LOCKED（锁定）：因质检或异常临时锁定。
